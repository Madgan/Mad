## 上线前要你批的 3 件事

1. **后台**：在 SIS 的 Supabase 加 4 张新表、1 个防刷触发器、1 个统计函数，不动现有的表。SQL 在 `launch.sql`，还没在正式库执行；已在本机临时数据库测过（`launch.test.sql`），可重复执行。
   - 公开访客只能新增答案，读不到任何一条原始答案，只拿得到统计结果。
   - 同一个 IP 每小时最多 3 份；全站每小时最多 60 份，就算有人伪造 IP 也只能灌这么多。
   - IP 只存加密哈希（sha256 + 数据库内随机生成的密钥），不存原始 IP，1 天后删除。
   - 上线前要在测试环境确认 Supabase 会传 `cf-connecting-ip`，否则防刷退回用 x-forwarded-for。
2. **网址**：已选 A（`rates.sistudio.app`）。
   - `rates.sistudio.app`：要你在域名商加一条 DNS 记录。品牌最好。
   - GitHub Pages 免费网址：不用动域名，但网址难看。
3. **去掉示例资料**：上线版从 0 份开始，每组少于 5 份不显示数字。不放任何假数字。
