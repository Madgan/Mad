# 圆圆识字岛（Yuan Yuan's Word Island）

一套给 5 岁孩子的识字游戏。中文为主，英语为辅。用 iPad 或手机浏览器打开就能玩，不需要安装，不调用任何付费接口。

## 8 个地点

| 地点 | 玩法 | 练的是什么 |
|---|---|---|
| 🌳 字的故事 | 点一张图，看它"变"成字，听字的来历 | 认识新字（字理识字、图像 + 声音 + 字形） |
| 🎣 小猫钓鱼 | 听圆圆说一个字，钓起对应的鱼 | 听音认字（检索练习） |
| 🃏 翻翻乐 | 图 ↔ 字、字 ↔ 英文配对 | 字和意思、英文的联系 |
| 🧪 魔法锅 | 自由组合两个字，变出新字（木+木=林） | 部件意识、会意字、形声字 |
| ✍️ 写字亭 | 跟着笔顺用手指描红 | 字形细节（游戏性质，不计对错） |
| 🚂 词语火车 | 选一个字让火车开走（火 + ? = 火车） | 组词、语素意识 |
| 🧺 分一分 | 把字拖进对的篮子（动物 / 大自然…） | 理解字义，不只认形状 |
| 🌻 我的花园 | 每个字是一棵花；口渴的花要答对才能长大 | 间隔复习，进度看得见 |

家长区：在小岛首页**按住右上角 ⚙️ 1.5 秒**。里面有学习进度、设置（每次时长、英语、拼音、主题）和完整的设计原理与陪玩建议。

## 文件

- `src/game.html`：游戏源码。字库、魔法锅配方、火车词语都在 `DATA-START` 和 `DATA-END` 之间。
- `index.html`：打包好的成品（源码 + 笔顺数据）。直接打开这个文件就能玩。
- `tools/build.mjs`：打包脚本，把字库里每个字的笔顺数据嵌进 `index.html`。

## 加新字

1. 在 `src/game.html` 的 `BANK_ROWS` 里加一行：`['字','拼音','English','图','词语','主题','字的故事（可空）']`。
2. 想加魔法锅配方就在 `RECIPES` 加一行；想加火车词语就在 `WORDS` 加一行（两个字都必须在字库里）。
3. 在仓库根目录运行：

```bash
npm i --no-save hanzi-writer-data@2.0.1
```

```bash
node kids-hanzi/tools/build.mjs
```

## 备注

- 学习进度存在这台设备的浏览器里，换设备会从头开始。
- 朗读用的是设备自带的语音。iPad 上如果没有声音，去 设置 → 辅助功能 → 朗读内容 → 声音 → 中文，下载一个普通话语音。
- 笔顺数据来自 [hanzi-writer-data](https://github.com/chanind/hanzi-writer-data)（Arphic Public License），描红用的是 [Hanzi Writer](https://hanziwriter.org)（MIT）。
