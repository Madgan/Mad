# 补充指令：等级（经验值）存进 SIS 账号

> 用法：如果已经把《SIS 虚拟办公室接入》主指令贴给 Claude Code，再把下面这段贴进同一个对话。还没贴的话不用这份，主指令已经包含这部分。

---

## 指令

在虚拟办公室接入的基础上，加一项：办公室的等级（经验值 XP）存进 SIS 账号，换手机打开等级一样，不会变回 LV 1。办公室前端已经改好，只需要后端配合。

1. 用户表加：
   - `office_xp`：整数，默认 0。
   - `office_xp_day`：日期。
   - `office_xp_day_gain`：整数，当天已经加了多少。
2. `GET {apiBase}{me}` 多回传 `xp`（就是 `office_xp`）。等级由办公室自己换算（每 100 XP 升一级），后端只存数字。
3. `PATCH {apiBase}{me}` 接受 `{ xp }`，规则：
   - 必须是整数。
   - **只能增加：** 比现在小的值直接忽略，回传现在的资料，不报错。
   - **同一天（马来西亚时间 UTC+8）最多增加 400：** 超过就回 400，不更新。换日时把 `office_xp_day_gain` 归零。
   - 成功后回传更新后的完整资料（含 `xp`）。
4. 这两条规则是为了防止有人改前端刷等级。等级只用来解锁衣服，风险低，不用做更复杂的验证。
5. 办公室的行为：
   - 打开时取账号和这台手机里较高的那个值；如果手机比较高（连上 SIS 之前玩过），会上传一次。
   - 之后每次拿到经验值，1.5 秒后送最新的总数。

### 验收

- [ ] 在手机 A 做任务拿经验值（例如去前台签到 +20），资料库的 `office_xp` 跟着增加。
- [ ] 换手机 B 打开 `/office`，左上角的等级跟 A 一样。
- [ ] 直接送一个比现在小的 `xp`，值不变。
- [ ] 同一天送超过 +400，回 400，值不变；隔天可以再加。

做完回报改了哪些文件、测试结果。
