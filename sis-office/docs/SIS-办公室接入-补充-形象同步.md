# 补充指令：形象存进 SIS 账号

> 用法：如果已经把《SIS 虚拟办公室接入》指令贴给 Claude Code，再把下面这段贴进同一个对话。还没贴的话不用这份，主指令已经包含这部分。

---

## 指令

在虚拟办公室接入的基础上，加一项：用户在办公室捏好的形象存进 SIS 账号，换手机或换浏览器打开时直接用账号里的形象，不用重新捏。办公室前端已经改好，只需要后端配合。

1. 用户表加 `office_avatar`（JSON，可以空）。
2. `GET {apiBase}{me}` 多回传 `avatar`：存过就回 JSON 物件，没存过回 `null`。
3. `PATCH {apiBase}{me}` 接受 `{ avatar }`，收到就整个覆盖。后端要检查：
   - 大小不超过 2 KB，必须是 JSON 物件。
   - 只保留这些 key：`gender`、`skin`、`hair`、`hairColor`、`top`、`topColor`、`bottom`、`bottomColor`、`shoes`、`hat`、`hatColor`、`glasses`、`watch`。其他 key 丢掉。
   - 值只能是 20 字以内的字串，或 0 到 50 的整数。不合格回 400。
4. 后端不用懂每个值代表什么，办公室读进来时会再检查一次。
5. 办公室的行为：
   - 第一次连上 SIS、账号里还没有形象时，会把这台手机上捏好的形象上传。
   - 之后每次在衣帽间保存都会更新。

### 验收

- [ ] 在手机 A 打开 `/office` 捏好形象，资料库里 `office_avatar` 有值。
- [ ] 换手机 B（或电脑）打开 `/office`，不会出现捏人画面，人物跟手机 A 一样。
- [ ] 在 B 的衣帽间换衣服，回到 A 重新打开也是新的。
- [ ] 送一个超过 2 KB 或有奇怪 key 的 `avatar`，后端回 400，或丢掉多余的 key。

做完回报改了哪些文件、测试结果。
